🌱 Most of my projects start with something I need in daily use and could not quite find. I like turning those small gaps into apps and extensions I can use myself, and share when they might be useful to others too.

🧩 For some projects, I use a structured agentic coding workflow. I start with the idea, define the architecture and constraints, steer the implementation, review the results, test them in practice, and decide what gets released. AI agents support the work; the responsibility stays with me.

🔍 For my public Contao extensions, I test changes in Docker environments across multiple complete Contao LTS versions and on my own live Contao installation before tagging and publishing.

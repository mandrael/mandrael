Most of my projects start with something I need in daily use and could not quite find. I like turning those small gaps into apps and extensions I can actually use.

#### Development

For selected projects, I use a structured agentic coding workflow centered on Claude Code, with Codex or other agentic coding tools assisting on specific tasks. I define the architecture, requirements, constraints, testing strategy, release decisions, and the standard a change needs to meet before it ships. Agents help with implementation, refactoring, tests, and review; final validation, maintenance, and responsibility stay with me.

For my public Contao extensions, I test changes in Docker environments across multiple complete Contao LTS versions, then validate releases on my own live Contao installation before tagging and publishing.
